  Mach-O section equality; installed /Applications copy is still build 11.

  checks and two qualitative stack captures. Main raw results were independently
  re-parsed. Measurements occurred under busy user background load, not at idle.

- Highest-value candidates are dimension-only Scene measurement, per-generation
  network aggregation caching and process demand based on actual layout content.
  The micro layout still averaged 2.38% without showing process information.
- Source and measurement limitations, secondary DNS/cadence/cache opportunities,
  exact per-window values and next validation steps are retained in
  `docs/evidence/2026-10-21-performance-review/`.

  changed. No correctness gate rerun was needed for a source-unchanged review.
  Only the owned isolated preview and its collectors were stopped.
